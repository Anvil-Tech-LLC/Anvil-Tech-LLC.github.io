# Anvil Tech LLC website

Static site for https://anvil-tech-llc.github.io/ (GitHub Pages, published from the `main` branch root).

- `index.html`: the studio home page
- `games/candy-unclip/`: the Candy Unclip page
- `privacy/`, `terms/`: the Privacy Policy and Terms of Service (the URLs given to TikTok and other platforms)
- `assets/`: stylesheet, logo and images

Plain HTML and CSS, no build step. Edit a file, commit, push, and Pages republishes within a minute or two.
